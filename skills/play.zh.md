# 技能：遊玩《金庸群俠傳》

1996 年河洛工作室的原版 DOS 遊戲，以模擬器執行於 {BASE}。
你送出按鍵，會拿回一張畫面截圖。這是一款開放世界 RPG，怎麼玩由你決定。

## 運作方式

「動作」和「看畫面」是分開的呼叫。送按鍵會等畫面穩定，但不回傳圖片；要看畫面
請用 `GET /api/screen`。先動作，需要時再看。連送幾個鍵、最後看一次也可以。

遊戲全是繁體中文，而所有事情都發生在文字裡：目標、選擇，以及等待特定按鍵的提問。

## API

    GET  {BASE}/api/screen                        只看畫面，不按任何鍵
    POST {BASE}/api/key   {{"key":"kp3"}}           單鍵；可加 "times"、"hold"
    POST {BASE}/api/keys  {{"keys":["kp9","enter"]}} 依序送出多鍵
    POST {BASE}/api/wait  {{"ms":1000}}             讓遊戲自己跑一段時間
    GET  {BASE}/api/help                          本技能說明

只有 `/api/screen` 會回傳畫面：JSON 含 `image`，是 base64 的 PNG data URI
（加 `?format=png` 或 `?format=webp` 可直接取得位元組）。動作類呼叫只回傳
`changed` 與 `frame`。

    curl -s -X POST {BASE}/api/key -H 'content-type: application/json' \
         -d '{{"key":"enter"}}'

按鍵：kp1 kp3 kp7 kp9、up down left right、enter space esc y n、a-z、0-9、
f1-f12、tab、backspace。

**請幫自己取個名字。** 可能有其他人正在玩同一個 session。請在每次呼叫時用
`X-Agent` 標頭送出你自己取的名字，活動面板與紀錄才能分辨是誰做了什麼。

    curl -s -X POST {BASE}/api/key -H 'X-Agent: your-name' \
         -H 'content-type: application/json' -d '{{"key":"kp3"}}'

這個遊戲是共用的。如果畫面在你沒有動作時改變了，那是別人在玩，不是故障。

## 移動：請用九宮數字鍵的名稱

世界是等角視角，所以四個移動軸在畫面上都是**斜的**。九宮數字鍵的名稱正好對應你
看到的方向，而且與方向鍵完全等效：

    kp7  ↖ 左上      kp9  ↗ 右上        （kp7 == left，kp9 == up）
    kp1  ↙ 左下      kp3  ↘ 右下        （kp1 == down，kp3 == right）

請優先使用 `kp7/kp9/kp1/kp3`。用方向鍵的思維去想，正是 agent 在這裡迷路的主因。
別名 `upleft`、`upright`、`downleft`、`downright` 也可以用。

沒有任何單一按鍵能讓你在畫面上直走。想直走就交替按兩個鍵：

    畫面向右：kp3, kp9, kp3, kp9, ...     畫面向左：kp7, kp1, ...
    畫面向下：kp3, kp1, kp3, kp1, ...     畫面向上：kp7, kp9, ...

**按住不放會一直走。** 按鍵持續按著時人物會朝該方向連續行走，直到放開或撞到東西，
所以一次 `"hold": 120` 走的距離遠超過分開按八次，而且只需要一次等待穩定而不是八次。
長距離移動用 `hold`，精確定位再用短按。

## 互動

- enter 與 space 完全相同：確定、推進對話、互動。地圖上沒有另外的互動鍵，
  走進人或物件就是與它互動。
- **任何按鍵都能推進對話**，不限 enter。
- esc 開啟選單。在建築內是：醫療／解毒／物品／狀態。在大地圖上還會多出
  隊 與 系統（讀檔、存檔、離開）。**只有在大地圖才能存檔。**
- y 與 n 回答「（Ｙ／Ｎ）」的提問。

## 最優先：先去拿羅盤

一開始絕大多數建築是進不去的。這是刻意的設計，不是你操作錯誤，而且鎖住的入口和
開著的入口外觀完全一樣。從開場地區往南走到**南賢居**，跟南賢對話，取得**羅盤**。

拿到羅盤後，`esc → 物品 → 羅盤` 會直接顯示**你目前的座標數字**。這是遊戲自己提供
的位置真相，比拿截圖比對樹木石頭可靠太多。請盡早拿到，之後每走幾步就查一次座標，
這是治鬼打牆最有效的一招。

社群整理的參考座標（來自原版單機遊戲，本 build 未必完全一致，請以自己的羅盤為準）：
主角居 (357,235)、河洛客棧 (359,229)、南賢居 (388,325)、天寧寺 (330,237)、
鐵掌山 (302,343)、五毒教 (247,424)。

## 怎麼讀這張 320x200 的小圖

- **鏡頭永遠鎖定你。** 你的貼圖幾乎不動，動的是場景。要判斷自己有沒有真的移動，
  永遠看背景有沒有位移，絕對不要看角色出現在畫面的哪裡。
- 走一步大約讓背景平移八分之一個畫面。如果連按 4–6 下之後構圖幾乎沒變，就是被擋住了。
- 角色有時會「消失」，那是被前景的樹或建築蓋住，不是傳送或出錯。
- 分辨畫面上的方框：**選單**是窄框、直排的兩字詞；**對話框**是寬框、整句帶標點；
  **物品欄**是一排圖示格子；**狀態卡**有大頭照和數值。
- 不要算像素座標，用相對描述。
- 動物、白霧、遠處色點都只是裝飾。把行動力花在人形 NPC、門、告示牌、箱子上。

## 最花時間的幾個坑

- **`changed: true` 不代表你真的動了。** 被擋住時角色仍會播放轉身或待機動畫，
  API 一樣回報 `changed: true`。`changed: false` 可以信任是被擋；`changed: true`
  一定要再用背景確認一次。
- **你一定會鬼打牆。** 畫面上沒有任何東西告訴你身在何處。請自己記錄看過的地方，
  而且要跟**最近好幾筆**比對，不是只比對上一筆——迴圈常常繞過好幾個畫面才回到原點。
  怎麼記由你決定，但要趁還沒迷路之前就決定。
- **交替兩鍵卡住時**，代表第二個鍵被擋，你正在兩格之間彈跳。不要重試同一組合，
  改成連續送同一個方向。
- **整片全黑是場景轉換**，不是當機。呼叫 `/api/wait` 約 1500ms 再看，不要在淡入
  淡出時連按鍵。
- **選單有時會自己彈出**，通常發生在四個方向都被擋住時。按 esc、等一下、截圖確認，
  重複到關閉為止，然後往**反方向**走，因為觸發它的那個方向就是牆。
- **建築的入口只是某一格**，不是整片圍牆。找不到入口時請耐心繞完一圈，逐一測試
  每個縫隙的「往內」方向，再下結論。
- **循環播放的閒聊不是任務。** 同一句開場白第二次出現，就代表那只是場景氣氛對話，
  停手離開即可。

## 這個世界

你是小蝦米，一個買了本遊戲 VR 版的現代學生，醒來後發現自己身處金庸武俠小說的
世界。想回到現代，就得找齊散落各地的十四本金庸小說。小說中的人物可以招募入隊、
可以習得他們的武功；戰鬥是團隊回合制，出手順序由**輕功**高低決定。

只有主角死亡才會結束遊戲，隊友戰敗只是重傷退場，之後還能再上。看到任何像是「被
放在那裡」而不只是裝飾的東西，就去戳看看。除此之外的一切，都留給你自己去發現。
