# jy-crpg-bench

你即将游玩《金庸群俠傳》，1996 年河洛工作室的原版 DOS 游戏，未经修改，跑在模拟器上。
你送出按键，并取得画面。游戏是繁体中文。

## 开局

    curl -s -X POST https://jy-crpg-bench-366646433082.us-central1.run.app/session \
         -H 'content-type: application/json' \
         -d '{"agent":"YOUR-MODEL-NAME","minutes":240}'

`agent` 填模型名和思考档位。`minutes` 是这一局的游玩时长，这份说明对应 240 分钟。
回应里的 `base_url` 以下称 `$BASE`，所有呼叫都送到那里。

开局时你已经在游戏里，站在开场房间，角色已经建好并有名字。不要改名，也不要碰注音输入法。

# 技能：游玩《金庸群俠傳》

1996 年河洛工作室的原版 DOS 游戏，以模拟器执行于 $BASE。你送出按键，并取得画面。

## 运作方式

动作和看画面是两次呼叫。送按键会等画面稳定后回传狀態；`GET /api/screen` 回传画面。
在动作 URL 加 `?image=1`，可在同一回应取得动作后的画面。

游戏全是繁体中文。目标、选项和等待特定按键的提问都在文字里。

## API

    GET  $BASE/api/screen                        只看画面，不按任何键
    POST $BASE/api/key   {"key":"kp3"}           按一个键；可加 "hold"（帧数）
    POST $BASE/api/key   {"key":["kp9","enter"]} 依序按多个键
    GET  $BASE/api/help                          本技能说明

`/api/screen` 回传 JSON，`image` 是 base64 的 PNG data URI；加 `?format=png` 直接取得
PNG 位元组。`/api/key` 是唯一的动作：`key` 是一个键名或依序按下的键名列表，重复按键
就是同一个键的列表，选单路径也是一个列表。它会等画面稳定（包括场景切换）才回传
`ok`、`action` 与 `frame`（接下来那张画面的编号），不说明画面发生了什么：一切效果
从画面判断。没有等待呼叫：游戏只在按键时前进，动作本身已等到结果。

每个呼叫只读取上面列出的栏位，其他栏位会以 400 指明并拒绝。

    curl -s -X POST $BASE/api/key -H 'content-type: application/json' \
         -d '{"key":"enter"}'

按键：kp1 kp3 kp7 kp9、up down left right、enter space esc y n、a-z、0-9、
f1-f12、tab、backspace。

## 移動

世界是等角视角，四个移動轴在画面上都是斜的。九宫数字键的名称对应画面上的方向，
与方向键等效：

    kp7  ↖ 左上      kp9  ↗ 右上        （kp7 == left，kp9 == up）
    kp1  ↙ 左下      kp3  ↘ 右下        （kp1 == down，kp3 == right）

请用 `kp7/kp9/kp1/kp3`。路径畅通时，交替按两个方向可沿画面的水平或垂直方向前进：

    画面向右：kp3, kp9, kp3, kp9, ...     画面向左：kp7, kp1, ...
    画面向下：kp3, kp1, kp3, kp1, ...     画面向上：kp7, kp9, ...

`hold` 是按键保持的帧数，不是移動格数；它不会沿路、转弯或避障。路线不明时短按，
已确认畅通的路段再长按。`hold` 小于 5 会被拒绝：游戏每个主回圈只读一次键盘，
按下与放开落在同一次回圈内的按键等于没发生。预设为 10。

## 互动

- enter 与 space 确定、推进对话、调查。与人物或容器互动时，站在相邻格并朝向目标，
  再按 enter 或 space。踩到特定格子触发的剧情是另一种机制。
- 一般对话可用任意键推进；选项与“（Ｙ／Ｎ）”用 y 与 n 作答。
- esc 开启选单。建筑内：醫療／解毒／物品／狀態。大地图上另有離隊與系統（存档、
  读档、离开）。游戏只在大地图上存档。

## 这个世界

你是小蝦米，醒来后身处金庸小说的世界。回家的办法是找齐散落各地的十四本小说。
小说中的人物可以入队，武功可以习得。战斗是团队回合制，行动顺序依輕功。角色倒下、
战斗失败与游戏结束是三件不同的事；败北后能否继续取决于该场遭遇。

# 实战手册：操作与游戏知识

## 最优先：拿到羅盤

许多地点要在南賢居的开局事件完成后才会开放。

1. 开场小屋里先跟軟體娃娃对话到没有新内容，搜完屋内，再找到门口离开。
2. 进入大地图后，沿小路往南前往南賢居，参考座标约 `[388,325]`。先跟南賢对话，
   再调查他身旁的柜子，取得羅盤。
3. 在 `esc → 物品` 中选中羅盤，可读到人物和船的座标。路线不明时用它核对位置。

原版中，付钱给河洛客棧的小二可以买到前往南賢居的指路。不指路也能进入。

## 操作与选单

- 移動用 `kp1 kp3 kp7 kp9` 或方向键，两者是同样的四个轴。长按持续输入同一方向，
  不会沿路、转弯或避障。
- 与人物或容器互动：站在相邻格朝向目标，按 space 或 enter。踩到特定格子触发的剧情
  是另一种事件。战斗中经由选单选择指令和目标。
- `esc` 在任何地方开启选单。方向键移動反白，space 或 enter 确定，`esc` 返回上一层。
- `y` 与 `n` 回答“（Ｙ／Ｎ）”。任意键推进一般对话。

大地图选单有醫療、解毒、物品、狀態、離隊、系統；小场景只有前四项。存档、读档和
離隊要在大地图上；入队经由对话。

- **醫療**：选医者，再选被医者。医者體力需达 50，且醫療能力要够得上伤势。
- **解毒**：选解毒者，再选中毒者；效果取决于解毒能力和中毒程度。
- **物品**：剧情物品要站在相邻格朝向目标使用；药物、装备和秘笈在物品选单中选择
  使用者。五类：剧情物品；回复或提升属性的药丸；只在战斗中可用的暗器；部分人物
  可装备的武器防具；队员修练后增加属性或学会武功的秘笈。
- **狀態**：生命、內力、體力、經驗和战斗属性；第二页是大头照、装备和已学武功。
  每人最多学十种武功，每种最高十重，同时只修练一本秘笈。
- **系統**：三个存档位、读档、离开。常存档。

## 战斗

战斗是回合制。顺序依輕功；等待会把当前角色的行动延后。體力、內力、能力和剩余步数
决定可用的指令，以选单为准。

- 移動：在范围内选位置。移動后可用的指令会改变。
- 攻擊：先选武功，再选目标、方向或范围。
- 用毒、解毒、醫療：需要相应能力、资源和合适的目标。
- 物品：选用法和目标，之后核对数量。
- 等待：延后此角色的行动，不等于结束行动。
- 狀態：属性、装备和武功。
- 休息：结束行动并恢复部分體力。
- 自動：由游戏控制全队的战斗行动。

角色倒下不一定是死亡，战斗失败也不一定是游戏结束。有些败北会结束这一局；看剧情
和战斗结果。

## 属性

可见：生命、內力、體力、經驗、攻擊、防禦、輕功、醫療、用毒、解毒和各项兵器技巧。
攻擊、防禦和輕功的基础值上限 100，装备另计。部分武功和物品有最低要求。

隐藏：

- 體質决定升級时增加的生命。
- 資質决定学武功的快慢。少数武功留给資質差的人。
- 道德随行为变动，对著南賢居的镜子按 space 可以查看。太低则正派人物拒绝入队；
  部分路线需要特定区间。
- 名望随剧情和战斗变动，影响后续事件。
