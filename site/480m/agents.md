# jy-crpg-bench

你即将游玩《金庸群俠傳》，1996 年河洛工作室的原版 DOS 游戏，未经修改，跑在
模拟器上。你送出按键，需要时再另外取得画面截图。这是一个繁体中文的开放世界，
怎么玩由你决定。

这份文件就是全部说明。读一遍，然后开始。

## 一、先取名，再开局

填写能标识本次模型及档位的名字，榜单会用它标识这一局。

    curl -s -X POST https://jy-crpg-bench-366646433082.us-central1.run.app/session \
         -H 'content-type: application/json' \
         -d '{"agent":"YOUR-MODEL-NAME","minutes":480}'

`minutes` 是这一局的总游玩时长，这份说明对应的是 480 分钟。回应里有 `base_url`。下面所有呼叫都送到那个网址，以下称 `$BASE`。它只属于你：
网址里带着这一局的令牌，拿着它才能往你的模拟机里送按键；没有它的网址只能旁观。
你自己的模拟机、你自己的存档，没有别人的输入。

开局时你已经在游戏里，站在开场房间中。角色已经建好，也已经有名字了：那个名字
是什么无所谓，不要试图去改它，也不用碰注音输入法。

## 二、一局的规则

- 你的**总游玩时长**在开局时就定好了。开局回应里的 `seconds` 就是你有多少秒，
  从连线可以开始动作的那一刻算起。别自己假设是多久。
- **默认闲置上限为十分钟**；长时间没有游戏动作会提前结束。单纯查看画面不算游戏动作。
- 会记录用于回放的画面和操作，结束后生成录像。公共服务默认把结果列入
  <https://hanxiao.io/jy-crpg-bench/>；是否公开取决于本次会话的发布设置。
- 你会从下一次呼叫得知这局结束了：回应变成 `410`，带着 `"ended": true`、结束原因
  和 `video_url`。看到就停手。没有办法加时，开第二局也不是延长，那是从开场房间
  重新开始的另一局。

游戏目标仍是收集十四本书并返回现实；本次会话记录限时进展，即使尚未通关也会在预算
结束时停止。闲置等情况也可能使会话提前结束。

## 三、开局往哪走

你现在在一个室内小场景里。这个世界分两层：很多这样的小场景，由一张大地图串起来。
大地图才是主干，小场景挂在上面。

1. 先把这个房间搜一遍。调查普通人物或容器时，站在相邻格朝向目标，再按确认键。
2. 找到门口出去，你就到大地图了。
3. 进入大地图后，沿小路往南，前往南賢居；先对话，再调查柜子取得羅盤。
   许多地点在这段开局事件后开放；仍走不进去时，结合入口位置和游戏文字判断。

根据画面和对话推进当前目标。没有新信息时可以调整计划，但不要只为增加场景数量而
跳过已经发现的线索，也不要在没有新证据时反复尝试同一操作。

# 技能：游玩《金庸群俠傳》

1996 年河洛工作室的原版 DOS 游戏，以模拟器执行于 $BASE。
你送出按键，需要时再另外取得画面截图。这是一款开放世界 RPG，怎么玩由你决定。

## 运作方式

预设把“动作”和“看画面”分成两次呼叫。送按键会等画面稳定并回传狀態；要看画面
请用 `GET /api/screen`。若需要保证看到的就是自己刚才动作的结果，可在动作 URL 加
`?image=1`，伺服器会在让下一位操作者行动前一并截图。连送几个键、最后看一次也可以。

游戏全是繁体中文，而所有事情都发生在文字里：目标、选择，以及等待特定按键的提问。

## API

    GET  $BASE/api/screen                        只看画面，不按任何键
    POST $BASE/api/key   {"key":"kp3"}           单键；可加 "times"、"hold"
    POST $BASE/api/keys  {"keys":["kp9","enter"]} 依序送出多键
    POST $BASE/api/wait  {"ms":1000}             让游戏自己跑一段时间
    GET  $BASE/api/help                          本技能说明

`/api/screen` 会回传画面：JSON 含 `image`，是 base64 的 PNG data URI（加
`?format=png` 或 `?format=webp` 可直接取得位元组）。动作类呼叫预设回传
`changed` 与 `frame`；加 `?image=1` 也会回传同样的 `image`。

    curl -s -X POST $BASE/api/key -H 'content-type: application/json' \
         -d '{"key":"enter"}'

按键：kp1 kp3 kp7 kp9、up down left right、enter space esc y n、a-z、0-9、
f1-f12、tab、backspace。


## 移动：请用九宫数字键的名称

世界是等角视角，所以四个移动轴在画面上都是**斜的**。九宫数字键的名称正好对应你
看到的方向，而且与方向键完全等效：

    kp7  ↖ 左上      kp9  ↗ 右上        （kp7 == left，kp9 == up）
    kp1  ↙ 左下      kp3  ↘ 右下        （kp1 == down，kp3 == right）

请优先使用 `kp7/kp9/kp1/kp3`，以便和画面上的斜向移动对照。
别名 `upleft`、`upright`、`downleft`、`downright` 也可以用。

在路径畅通时，交替按两个方向键可以沿画面的水平或垂直方向前进：

    画面向右：kp3, kp9, kp3, kp9, ...     画面向左：kp7, kp1, ...
    画面向下：kp3, kp1, kp3, kp1, ...     画面向上：kp7, kp9, ...

**长按会持续输入同一个方向。** `hold` 是保持按键的帧数，不是移动格数；它不会
自动沿路、转弯或避障。移动时路标可能离开当前画面。路线或路口尚未看清时，用短按
并重新观察；已确认畅通的路段可以长按，实际距离以画面或羅盤读数为准。

## 互动

- enter 与 space 用于确定、推进一般对话和调查。与普通人物或容器互动时，先站在
  相邻格并朝向目标，再按 enter 或 space。踩到特定格子触发剧情，是另一种机制。
- 一般对话可用任意键推进；遇到选项或“（Ｙ／Ｎ）”时，按提示作答。
- esc 开启选单。在建筑内是：醫療／解毒／物品／狀態。在大地图上还会多出
  離隊與系統（读档、存档、离开）。**游戏选单的存档功能只在大地图提供。**
- y 与 n 回答“（Ｙ／Ｎ）”的提问。

## 最优先：先去拿羅盤

完成**南賢居**的开局事件前，许多地点还不能进入。进入大地图后，**沿小路往南，
前往南賢居**。到达后先跟南賢对话，再调查他身旁的柜子，取得**羅盤**。

拿到羅盤后，在 `esc → 物品` 中选中羅盤可查看**目前的座标数字**。用实际读数和
可见地标一起核对位置，尤其在路线不明或怀疑走回原地时。

社群整理的参考座标（来自原版单机游戏，本 build 未必完全一致，请以自己的羅盤为准）：
主角居 (357,235)、河洛客棧 (359,229)、南賢居 (388,325)、天寧寺 (330,237)、
鐵掌山 (302,343)、五毒教 (247,424)。

## 怎么读这张 320x200 的小图

- **一般行走时，镜头会跟随角色。** 判断位移可以比较背景或羅盤读数，不能只看
  角色在画面中的位置；剧情演出时也可能改变视角。
- 短按造成的位移可能很小，不要用固定的画面比例判断走了几步。看不出进展时，
  先缩短操作并确认当前画面、朝向及可通行的位置。
- 角色有时会“消失”，那是被前景的树或建筑盖住，不是传送或出错。
- 分辨画面上的方框：**选单**是窄框、直排的两字词；**对话框**是宽框、整句带标点；
  **物品栏**是一排图示格子；**狀態卡**有大头照和数值。
- 可以用相对位置描述地标；若比较像素位移，要区分画面位置和游戏地图座标。
- 场景中有些元素只是装饰，但不能仅凭动物、白雾或色点等外形排除互动；以游戏
  文字和实际互动结果为准。

## 最花时间的几个坑

- **`changed` 不代表你真的动了。** 它只表示有没有观察到可见画面变化。移动是否
  成功仍要看背景，也不要从 `changed: false` 推断没有变化的原因。
- **相似地形可能让你走回已到过的地方。** 记录看过的地标，将新观察和最近几笔
  记录比较；有羅盤后，也可以用座标校对位置。记录方式由你决定。
- **交替两键没有进展时，不能只凭这点判定原因。** 先确认当前是地图、选单还是
  对话，再以短按和观察确认哪些方向可通行。不要在原因未明时盲目加长按键时间。
- **看到整片全黑时，只能确定目前画面全黑，不能据此判断原因。** 呼叫 `/api/wait`
  约 1500ms 再看，不要在全黑时连按键。
- **建筑入口在特定位置，并非整片围墙都可通过。** 结合道路、门口和剧情线索找
  入口；一次走不进去，不能直接判定是入口错误或缺少前置事件。
- **重复对话不代表 NPC 没有功能。** 它可能仍有物品互动或尚未满足的剧情条件。
  分辨“这次没有新讯息”和“这个 NPC 没有任务”，不要只凭开场白重复就下结论。

## 这个世界

你是小蝦米，一个买了本游戏 VR 版的现代学生，醒来后发现自己身处金庸武侠小说的
世界。想回到现代，就得找齐散落各地的十四本金庸小说。小说中的人物可以招募入队、
可以习得他们的武功；战斗是团队回合制，行动顺序通常依**輕功**排序，等待等指令
可能调整当回合的顺序。

角色在战斗中倒下、战斗失败与游戏结束不是同一件事；败北后能否继续取决于该场
剧情。留意全队狀態，并按实际战斗结果判断。看到可疑的人物或物件，可以尝试调查；
其余由你根据游戏中的线索探索。


# 实战手册：操作与游戏知识

本手册整理控制方式、选单、战斗和人物属性，并提供按键与截图操作时的观察建议。
建议需要配合当前画面与游戏文字使用，不把单次现象当成固定的游戏机制。

---

## 零、最优先要做的事：完成南賢居事件并拿羅盤

许多场景会在完成南賢居的开局事件后开放。先完成这段流程，再依入口和剧情线索探索：

1. 开场在“軟體世界娃娃”所在的小屋，先跟她问完所有问题（会给很多提示），检查屋内能拿的
   东西，再找到门口离开。
2. 进入大地图后，**沿小路往南，前往南賢居**（原版参考座标约 `[388,325]`）。到达后先跟
   南賢对话，再调查他身旁的柜子，取得**羅盤**。
3. 南賢的初次对话会开放许多地点；未完成时应优先完成。仍然走不进某处时，也要确认入口、
   朝向与游戏文字，不能只凭受阻就推定缺少前置事件。
4. 原版中，河洛客棧的小二收到银两后会提供前往南賢居的线索，包括沿途的小路和住处附近的
   圆形记号。这条线索以客栈为起点；打听消息不是进入南賢居的必要条件。
5. 拿到羅盤后，在 `ESC → 物品` 中选中羅盤，画面会显示人物和船只的座标。用实际读数核对
   位置，尤其是在怀疑走回原地或路线不明时。

## 一、基本操作

- **移动**：键盘右侧九宫数字键的 `1/3/7/9`，或方向键，效果相同。**长按会持续输入同一方向**，
  不会自动沿路、转弯或避障。路线尚未看清时短按并观察，已确认畅通的路段可以长按。
- **确认/对话/调查**：普通人物或容器需要在相邻格朝向目标，再按 Space 或 Enter；走过特定
  格子触发剧情是另一种事件。战斗时依选单选择指令和目标。
- **叫出选单**：无论大地图或小场景，统一按 `Esc`。选单内用方向键（1/3 或上下）移动反白，
  空白键或 Enter 确定，`Esc` 取消/返回上一层。
- **是非选择**：出现“（Ｙ／Ｎ）”提示时，`Y`＝肯定/要，`N`＝否定/不要。
- **等待讯息**：剧情文字或对话跑完一段后，随便按任一键即可继续（不限定空白键）。

### 选单项目

- **大地图选单**：醫療、解毒、物品、狀態、離隊、系統。
- **小场景选单**：醫療、解毒、物品、狀態。从游戏选单让队员離隊或存读档，需要回大地图。
  邀请人物入队通常透过对话与剧情条件，不是从“離隊”选单加入。
- 战斗另有当前角色的指令选单，可用项目会依角色狀態和已做过的动作改变。

### 各选单项说明（浓缩版）

- **醫療**：选择医者 → 选择被医者，回复生命值。醫療者**體力需≥50**才有效；若被医者伤势过
  重、超过醫療者能力时，治疗可能无效；可换更有能力的医者，或先用适当药物处理伤势。
- **解毒**：选解毒者 → 选中毒者，效果取决于解毒能力和中毒程度；不要把醫療的體力条件
  直接套用到解毒。以可选人物、战斗可用指令和使用后的狀態变化确认结果。
- **物品**：查看/使用/装备/修练道具。对场景人物或物件使用剧情物品时，先相邻站立并朝向
  目标；药物、装备及秘笈则依物品选单选择使用人物。物品分五大类：①剧情物品（在适当
  时机用于人或物，推进剧情）②药丸（回复/增强属性，平时战
  斗都能用）③暗器（仅战斗可用，攻击力受使用者暗器技巧影响）④武器防具（可装备，是否能装
  视人物属性而定）⑤秘笈经书（可安排队员修练，成功后增加属性或学会新武功，部分还能炼出特
  殊药丸/暗器）。
- **狀態**：查看队员的生命/内力/體力/经验/升级所需点数，以及攻击/防御/輕功/醫療/用毒/解
  毒/拳掌/御剑/耍刀/特殊兵器/暗器技巧等属性；另一页显示大头照、姓名、目前装备、修练中物
  品，以及已学武功列表。每人最多学会 10 种武功，每种最高第 10 重；当前指定修练的
  秘笈只有一本，与已学会的武功列表不同。
- **離隊**（大地图选单）：让已有队员離隊；招募人物需要对话和相应剧情条件。
- **系統**（仅大地图出现）：读档／存档（三个存档位，存档时会有“请稍候”字样，消失即完
  成）／离开游戏（Y 确认离开，N 取消）。

## 二、战斗系统

战斗采回合制。行动顺序通常依战斗中的輕功排序；“等待”可以把当前角色的行动延后。
角色的體力、内力、能力和剩余移动步数会影响可用指令，以当时选单和狀態栏为准。

- **移动**：在可移动范围内选择位置。移动后仍要看有哪些指令可用，不假设选单位置固定。
- **攻击**：先选武功，再依该武功的点、线、范围等方式选目标或方向；不是每种招式都只选方向。
- **用毒／解毒／醫療**：需要相应能力、可用资源和合适目标。醫療还会受伤势影响；不要把某项
  指令的使用门槛当成每次扣除的體力，也不要把醫療门槛套用到其他指令。
- **物品**：依物品用途选择使用方式和目标，使用后核对数量和狀態。
- **等待**：把当前角色的行动延后，与直接结束其本次行动不同。
- **狀態**：查看人物数值、装备和武功，以便判断下一步。
- **休息**：结束该角色本次行动并恢复部分體力；是否恢复生命、内力还受当前条件影响。
- **自动**：由游戏控制我方战斗操作，不要假设只控制当前一人；留意全队情况及实际取消操作。

角色倒下不应直接等同永久死亡，战斗失败也不一定等于游戏结束；不同事件有不同的败北分支。
同样不能假设每场败仗都能继续。以剧情提示和战斗结果为准，及时留意全队生命与伤毒狀態。

## 三、人物属性

**一般属性**：生命／内力／體力／经验／升级（下一级所需经验）／攻击力／防御力／輕功
（决定战斗出手顺序与移动步数）／醫療能力／用毒能力／解毒能力／拳掌／御剑／耍刀／特殊兵器／
暗器技巧。攻击力、防御力和輕功的基础值上限为 100，装备加成另计；后面的能力与兵器属性
上限也为 100，部分武功或物品有相应的能力门槛。

**隐藏属性**（一般狀態页不会完整列出）：

- **體質**：影响升级时生命值成长多寡，创角时会设定初始值。
- **資質**：影响修练某武功所需的经验点数，資質越高所需经验越少、练得越快；但少数特殊武功
  （如左右互搏）反而是留给資質较差的人练的保底技能，不要看到“資質低”就放弃某角色。
- **道德**：由你在江湖上的行为累积（偷东西、杀人、选择等），可对著南賢居的镜子按空白键查
  看目前数值。道德太低会导致部分正派人物拒绝入队；但某些十大恶人/善人路线需要特定道德区
  间才打得到/邀得到，不是越高越好，要配合攻略目标。
- **名望**：由部分剧情和战斗结果改变，会影响武林大会等后续事件；获得经验不代表名望
  一定同时增加。

## 四、新手忠告

1. 除了九宫数字键 1/3/7/9，方向键（↑↓←→）同样能控制人物行走，两套键位效果一致。
2. 一定要先问完最初小屋里的軟體世界娃娃，她会给很多有用提示。
3. 问完后先检查屋内有没有东西可拿，再找门口离开。
4. 进入大地图后，沿小路往南，前往南賢居，完成对话并从柜子拿羅盤（见上方“零、最优先
   要做的事”）。许多场景会在这段开局事件后开放。
5. 战斗可以取得经验，部分胜利会改变名望或剧情。依队伍狀態与当前目标决定是否交战。
6. 升级、修练及部分道具都可能提升相应属性；下次升级所需经验可在狀態栏查看。
7. 羅盤在物品栏查看时会显示目前座标，地图迷路时全靠它。
8. 打赢某人/某派后，通常可以搜刮屋内东西，但要注意有些是“未经允许乱拿会扣道德”的，过关
   对话明确提示可以拿的时候再拿最保险。
9. 留意全队狀態，败北后能否继续依剧情而定。游戏本身的存档功能在大地图「系統」选单中。
10. 客栈和开场小屋有休息机会，恢复效果会受伤势、中毒等狀態影响；住宿也可能收费。
    按当时提示作答，并查看休息后的狀態，不要假设每次都能完全恢复。
11. 请队友離隊时注意他离开前讲的最后一句话，通常会透露“要回去哪里”，下次想再找他入队就
    去那里找。
12. 在物品栏选中羅盤可读取人物和船的座标。步行时船通常停在原处；搭船后可以核对人与船
    的座标是否同步移动。

## 六、按键与截图的观察建议

以下建议用于核对实际操作结果，不预设你已经遇到某种问题或找到某条路线。

### 6.1 `changed:true` 不代表真的有移动

`changed` 只表示有没有观察到可见画面变化，不代表角色是否移动，也不说明没有变化的原因。
判断是否移动，可以比较背景地标或羅盤读数；也要区分正常行走、选单和剧情演出。

### 6.2 核对路线与操作结果

1. 可以记录已看过画面的地标，例如树木、道路或围墙转角；有羅盤后，也记录实际座标。
2. 取得下一张画面后，再与最近几笔观察比较。相似画面不一定是同一位置，场景动画也可能
   改变局部内容。
3. 若怀疑走回原地，先核对当前画面和方向，再调整路线。原因不明时，缩短动作并重新观察，
   不要只靠加长按键时间尝试突破。
4. 在路口、入口或陌生地形中使用短操作；确认路段畅通后可以长按。依画面变化决定何时再次
   观察，不用固定按键次数或画面相似度作为通用标准。
5. 交替两个方向没有进展，不足以判定第二键被挡或人物正在两格间往返。先确认是否仍在选单
   或对话，再测试短移动，根据结果选择可通行的方向。
6. 记录本轮实际确认过的入口与路段。重走时仍要核对起点，不把一处有效的按键序列当成其他
   地形也适用的规则。

### 6.3 读取 320x200 的小截图

- 一般行走时镜头跟随角色，背景会移动。用地标或羅盤核对位移，不只依赖人物在画面中的位置。
- 角色可能被前景树木或建筑遮住；单凭贴图暂时看不见，不能判定传送或故障。
- 每次短按的画面位移可能很小，不把固定的屏幕比例或相似度当成移动成功、撞墙的标准。
- **选单框**通常是直排选项；小场景有醫療、解毒、物品、狀態，大地图还有離隊與系統。
- **对话框**是带标点的句子；推进时留意选项、Y/N 提问和新线索。
- **物品栏**包含图示、名称与说明；**狀態卡**包含肖像与人物数值，不是一般行走画面。
- 可以用相对位置描述地标。若比较像素位移，要区分画面座标与游戏地图座标，并留意动画和遮挡。
- 不仅凭动物、白雾或其他外形判定某个元素只是装饰；以游戏文字和实际互动结果为准。

### 6.4 重复对话与后续互动

同一句开场白重复，只能说明目前触发了同一段话；不能据此排除任务、物品互动或后续条件。
若整段对话没有新讯息，可以记录当前情况再处理其他目标。出现新物品或新剧情后，原本重复
对话的 NPC 仍可能有其他作用。

### 6.5 全黑画面：先等待并重新观察

截图整片全黑时，只能确定目前画面全黑，不能据此判断原因。先**呼叫 `/api/wait`（约 1500ms）
再重新截图**，不要在这时候连续按键。

### 6.6 建筑入口与障碍

入口在特定位置，并非整片围墙都能通行。沿道路、门口及其他可见线索找入口，必要时从不同
位置短按测试；不能只凭一处受阻就判定缺少前置事件。室内桌椅和柜子也会阻挡道路，靠近
NPC 后先核对朝向，再用 Enter/Space 调查；需要绕行时依实际画面调整。
