# Defect ledger for the jy-crpg-bench paper (verified facts only)

Sources: `figures/catalog_snapshot.json` (published catalogue 7 Sep 2026, 24 rows),
`figures/numbers.tex` (regenerated by `figures/emit_numbers.py`), `figures/make.py`
(verified runnable: 19 scored sessions, 8 world-map latches, 4 fade-corroborated),
`server/server.py` and `server/warden.py` (metric semantics).

## A. Claims in main.tex that are now wrong

1. "no agent leaves the opening scene" / "every run ends level 1, zero
   experience". The catalogue now has 8 sessions whose screen latches the
   world-map signature and 4 with a corroborated fade-to-black, so the
   unbroken-floor claim in the abstract, intro, §4.1 headline and Figure
   ladder caption is stale. Fact: 8 latches, 4 corroborated, median latch
   493.5 s.
2. "Across six frontier models": 14 distinct labels over 19 scored sessions
   (17 model sessions, 2 random), 6 vendor families by label prefix.
3. Figure ladder caption repeats the claim in (1).
4. Table 1 row labels: single runs enumerated as "one run per system";
   catalogue has repeated labels (claude-fable-5-1 three runs, gemini-3.7-flash
   two, glm-5.3-flash two, random two), so "one run per system" is wrong and
   the repetition spread (gemini 0.068 vs 0.767) is a headline-worthy fact.
5. Number-of-actions ranges quoted ("300-1,400 actions"): observed scored
   range is 26-720 actions, median 98; plus 5 llm/<u>probe sessions never
   issued a key. Recompute and cite as macros.
6. "six frontier models ... Gemini-3.7-Flash, Grok-4.6, Qwen3.8-27B":
   labels also include gpt-5.6-sol, codex variants, glm-5.3-flash, and a
   never-started gpt-5.2-codex. Vendor roster in prose must match catalogue.

## B. Pipeline bugs

7. `figures/horizon.pdf`: duplicate agent labels collide (three
   "claude-fable-5-1", two "claude-opus-5", two "gemini-3.7-flash"); rows
   must be unique-keyed (append run id suffix) or the reader cannot map a row
   to a table row or replay.
8. `figures/make.py` `figure_ladder`: unreached rungs and *unmeasured* rungs
   both render nearly identical pale grey, so the honest distinction the text
   makes is invisible in the figure.
9. `figures/horizon.pdf`: the unmeasured/unverified marker is invisible
   (hatch on light grey at print scale).
10. `figures/behaviour.pdf`: long-tail metrics (TTFA 219.5 s) compete with
    0.5 s values on a linear axis; log scale or annotated free text needed.
11. `figures/emit_numbers.py`: silently `pass`es on malformed rows; if the
    snapshot ever contains a row missing `meaningful`/`actions`, a mean is
    emitted over a shorter list without saying so. Never compute a statistic
    over a silently shortened list.
12. `tables/` empty although `figures/make.py` claims to write tables; no
    `make_table.py` in `figures/`, so the paper's appendix tables are hand
    typed against a moving catalogue. Add `figures/make_table.py` emitting
    `tables/`.

and Δ SALAD (arXiv 2502.05559 low-resolution/document robustness),
SateLab? -> verified: VideoGameBench arXiv 2505.18134 (0.48% completion,
documented detector opacity), ARC-AGI-3 arXiv 2603.24621 (interaction budgets,
observable task structure, no world-model access).

19. No positioning table. Reference papers carry a compact comparison table of
    capability axes (environment fidelity, action space, OOD source, scoring
    ground truth, horizon, public leaderboard, contamination protocol). We must
    add one table and keep it factual (supported by cited numbers only).
20. No architecture figure. We describe observation/action/write-back and
    measurement but never draw the loop, the two channels (emulator memory vs
    pixels), or where the honest-measurement shims sit. A TikZ figure lands
    the contribution better than prose.
21. Scoring theory thin. Need an explicit metric definition list (statistic,
    unit, why it is valid, what it is not), and a measurement-validity
    subsection treating detector false-positive/false-negative design rather
    than narrating failures.
22. Contamination/treatment of prior knowledge asserts the obsolete pitfalls
    section instead of a contamination protocol. Replace with a protocol:
    current date knowledge, unseen map geometry, evidence count control, and
    freeze dates. No negative result narration.
23. Reproducibility: pin the leaderboard snapshot date, run ids, catalogue
    SHA? At minimum cite the published catalogue snapshot and the exact date,
    and report every statistic from generated macros.

  inventory" (§baseline) can only be partially confirmed (skills<=1, exp==0,
  level==1 in the catalogue subset). Fix: read the level/exp/items fields out
  of each session summary at generation time, or drop the inventory sentence.

  tables/family.tex) were being built but never \input -- the computed stats
